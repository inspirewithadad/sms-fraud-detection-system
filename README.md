# 🛡️ SMS Fraud Detection System

An intelligent SMS Fraud Detection System built with Machine Learning and Streamlit.

## Features

- Real-time SMS fraud detection
- Naive Bayes classifier
- Logistic Regression classifier
- Linear SVM classifier
- Majority voting decision
- Confidence scores
- Keyword explainability
- URL security analysis
- Batch CSV prediction
- Download prediction results

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Joblib
- TF-IDF Vectorizer
